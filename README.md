# CPCS 204 — Interactive Data Structures (Arabic / English)

نسخة ثنائية اللغة من الموقع التفاعلي لمقرر Data Structures I.

## اللغات
- العربية — RTL
- English — LTR

زر اللغة موجود أعلى الصفحة، واختيار المستخدم يُحفظ تلقائيًا في المتصفح.

## المميزات
- 10 فصول.
- شرح عربي وإنجليزي.
- محاكاة تفاعلية.
- اختبارات قصيرة مع تصحيح فوري.
- تتبع تقدم المستخدم.
- Dark Mode.
- دعم الجوال.
- التحويل بين RTL وLTR تلقائيًا.

## الملفات
- `index.html`
- `styles.css`
- `content.js`
- `app.js`

## النشر على GitHub Pages
1. أنشئ Repository جديدًا، مثال: `CPCS204-Interactive`.
2. ارفع الملفات إلى جذر المستودع.
3. افتح `Settings > Pages`.
4. اختر `Deploy from a branch`.
5. اختر `main` و `/ (root)`.
6. اضغط Save.

الرابط سيكون غالبًا:
`https://YOUR-USERNAME.github.io/CPCS204-Interactive/`

## تعديل النصوص
كل محتوى العربية والإنجليزية موجود في `content.js`.
